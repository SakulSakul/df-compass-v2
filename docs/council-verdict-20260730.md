# DF COMPASS v2 구조 개선 통합 심의 — 심의 결과 (2026-07-30)

> council 5인(역산·문제분해·유추·순진한질문·의존성그래프) + 리뷰어 2 완주,
> 결측 0. 심의 주관 = 감리자(Cowork). 원문 등재 — 이 파일이 심의 결과의
> 정본이다. **상태: 사용자 판정 대기** — 확정 시 일괄 구현 지시서 발행.

## 확정 설계 (8항)

1. **보장 계층**: doc_router+force_include 이식 — 라우팅 청크를 리랭크 풀
   주입 + 최종 top_k 예약석 1~2석(컷 면제), 라우터 저확신 시 no-op 폴백
   (add-only 불변식). rerank_pool 15→25, top_k 3→5, neighbors ±2→±1,
   중복 제거 후 총 청크 상한 8.
2. **CREDO**: 앱 레이어 프록시 명단 상수(CREDO·징계기준) + 리랭크 감점 +
   top_k 내 프록시 ≤1. 원장 등재 철회 기각(P3d 경보 오염). 원문 확보 게이트
   제외·승격 트랙. 제3 프록시 부재 확인 프로브 추가.
3. **conf**: 연속값 폐기 → 결정론 서수 4등급 — HIGH(원문 ok) /
   MEDIUM 상한(프록시 포함) / LOW(강등) / UNVERIFIED(앵커 0 별도 상태).
   앵커 수 포화 함수만. pass/degrade/block 동결. conf 소비처 확인 선행 —
   action 게이트 입력이면 임계 재매핑 별도 승인.
4. **번호체계·합성 계약**: 원장 SELECT 로 문서별 앵커 사전(조문형 25 /
   C-class 76) 파생, 합성·verify 동일 사전 공유. 조문형 = 투입 청크 실재
   조번호만(D1 차단), C-class = 조번호 금지·문서명+섹션 인용(am 원천 차단),
   인용 형식 의무(D2 차단), 문서명 실재 검증 추가(P3b 봉쇄).
5. **앵커 0**: 구현 전 읽기 전용 재파싱 3분류 프로브(추출기 실패 / 문서수준 /
   실제 무인용) → 처방 배분.
6. **지연·계측**: p50 ≤ 23.3s 하드(v1 실측 앵커, 깊이 동등 조건 병기) ·
   목표 20s. p95 기록만(기준 설정 보류). 검색 내부 계측(단계 타이머 +
   청크·토큰 하니스 기록) = 재검증 성립 조건.
7. **순서·통과 기준**: ⓪ 프로브 4종(앵커0 / conf 소비처 / 원장 소재 /
   청크 메타 조번호 + 제3 프록시) → ① 계측 → ② 합성 계약·conf(비검색) →
   ③ 보장 계층+감점·쿼터(검색). 계층별 기능 플래그 필수.
   **통과 기준**: B+A' 7건 전건 / D≥4 / 기존 38쌍 회귀 0 / neg 6/6 /
   위조 8건 비강등 0 / 프록시 전용 HIGH 0 / 비수록 홀드아웃 구어체 3문항
   회수(사전 수록 문항 채점 제외) / p50 ≤ 23.3s.
8. **컷오버**: 조건 방어. 8/10 은 공수 추정 접수 후 확정. 슬립: 단일 축
   +1주, 다축 설계 재심의. 위조·neg 면제 불가.

## Kill Criteria
- 위조 비강등 ≥1 → 롤백·동결
- 라우터 정확도 <90% → 보장 계층 재설계
- 홀드아웃 3문항 0 회수 → 질의 재작성 계층 신규 심의
- 청크≤8 에서 p50>23.3s → 상한 재협상
- 프록시 쿼터發 신규 미스 → 쿼터 재심의
- conf=action 입력 + degrade 급증 → 산식 재심의
- 플래그 미구현 + 재검증 실패 → 슬립 확정
